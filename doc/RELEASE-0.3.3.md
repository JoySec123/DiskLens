## 主要功能

- 多个授权目录统一扫描，自动合并重复或父子重叠范围，并支持排除规则。
- 概览、目录分析、文件类型、大文件、完整索引查询、扫描历史与同范围比较。
- 只读重复文件检测：完整 SHA-256 与逐字节确认，跳过链接、特殊文件和变化中的文件。
- 完整筛选结果 CSV 导出，防电子表格公式注入。
- 独立保留 365 天 / 2,000 条空间账单，展示一级目录变化和文件系统容量。
- 每日定时巡检、扫描速率和最长时间设置，以及增长、容量和覆盖提醒。
- 白色工作区与左侧导航；嵌入 fnOS 窗口时只显示一个应用标题。

## 0.3.3 修复

- 补齐闲置状态下的账单、汇总和提醒过期维护；不影响最近 20 次完整索引或用户源文件。
- 包含 0.3.2 的 fnOS 网关端口兼容修复：正常同源扫描不再误报“不允许跨站操作”。
- 写操作仍要求应用自定义请求标记并校验管理员身份；真正跨站请求、缺少标记的请求和非管理员请求继续被拒绝，不启用 CORS。

- 使用 Go 1.26.9 重新构建；`govulncheck` 未发现项目可达漏洞。旧 Go 1.26.4 构建包不得继续分发。

## 数据与安全边界

- 只读取目录元数据；仅在用户主动启动重复检测时读取候选文件内容。
- 不删除、移动、重命名或自动清理用户文件，也不提供相关 API。
- 查询、导出、比较和重复结果都会重新核对当前 fnOS 目录授权；任一扫描根撤权后隐藏整个快照。
- 统计的是文件逻辑大小，不等于磁盘实际占用；快照、稀疏文件、压缩、reflink 和硬链接会造成差异。
- 重复结果表示内容相同，不是自动删除建议；应用不计算快照或 reflink 的真实可回收空间。
