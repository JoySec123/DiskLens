# DiskLens 0.2.0 测试版

## 本次新增

1. 多授权目录合并扫描、父子目录去重、排除规则。
2. SQLite 全文件索引，支持目录逐层分析、全量筛选、排序、分页和路径复制。
3. 文件系统容量与文件逻辑大小分开显示。
4. 最近 20 次扫描历史、应用重启恢复、同范围记录对比、CSV 完整筛选导出。
5. 只读重复文件检测：全内容哈希后逐字节确认，跳过硬链接别名、链接、变化文件；限速、取消与分组分页。
6. 保留白色简约布局和左侧页签，移动端高级筛选可展开。

## 安装

- Intel/AMD：`dist/DiskLens-0.2.0-amd64.fpk`。
- ARM64：`dist/DiskLens-0.2.0-arm64.fpk`。
- 在飞牛应用中心手动安装对应安装包升级，保留已有目录授权。
- 管理员打开应用，先扫描小型测试目录；0.1.1 没有磁盘历史，升级后需要重新扫描。
- 索引保存在应用运行数据目录，不存放在用户共享目录。历史文件列表和 CSV 含路径信息，应按私有数据管理。

## 验证清单

- [ ] 真机网关入口、桌面图标与管理员访问。
- [ ] 授权目录新增、撤销和权限不足的错误状态。
- [ ] 两个目录扫描、排除、停止任务，确认文件没有被修改。
- [ ] 搜索原 Top 50 以外的文件、目录逐层进入、筛选/排序/分页。
- [ ] 停止并启动应用后历史仍存在，两个同范围记录可以对比。
- [ ] 用已知相同/不同内容文件验证重复检测，限速与停止生效。
- [ ] CSV 可下载，文件名和路径正确，记录不受页面条数限制。

上述清单需要用户在 fnOS 设备完成；本机验证不能替代设备验收。

## 边界

- 不包含删除、迁移或自动清理。文件管理器直达需要微应用 SDK 接入及宿主验证，本轮提供复制路径。
- 大小是逻辑大小，重复大小不是物理可回收空间；硬链接、快照、稀疏文件及 reflink 会造成差异。
- 修改时间不代表最后访问时间。历史“消失”也可能来自移动、权限变化或扫描跳过，不能直接判为删除。
- 重复检测读取文件内容，会产生磁盘 I/O，默认 32 MiB/s；进程重启后需重新检测。已存在的备份副本可能是有意保留。
- 普通扫描 30 分钟超时；内核 I/O 阻塞时停止需等待系统调用返回。
- 历史自动保留 20 份，索引空间按文件数和路径长度增长；清理旧索引不会删除原文件。
- 授权 API 文档要求 fnOS 1.2.0401+；旧版环境变量回退修改授权后需重启应用，网关兼容性待真机验证。
