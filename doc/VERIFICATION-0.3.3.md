# DiskLens 0.3.3 验证记录

日期：2026-10-19。

## 修复

继承 0.3.2 的重复标题与跨站误判修复。本次补全长期账单的过期机制：

- 无新扫描时，超期账单及对应提醒也不会从 API 返回。
- 启动及每小时闲置维护执行物理清理，定时扫描未开启也会维护。
- 磁盘任务运行期间暂缓维护，后续再次检查，避免争抢扫描事务。
- 过期摘要不再作为空间增长提醒的基准。
- 不删除用户源文件，不改变独立保留的最近 20 次完整索引，不清除巡检配置。

过期清理仅针对应用自身 SQLite 中的历史记录。数据库空间由 SQLite 后续复用，不承诺清理后文件大小立即减小。
