# DiskLens 0.1.1 测试版

## 修复

- 授权目录未与扫描服务接通，启动工作目录为 / 时可能扫描系统目录。
- 扫描请求一直等待完成，页面只有“扫描中”而看不到进展。
- 大文件排行只统计根目录文件，遗漏所有子目录。
- 初次无授权后刷新，开始扫描按钮无法重新启用。
- 图标是纯色方块，缺少可识别图形。

## 变化

- 采用白色工作区和左侧导航，提供概览、目录分析、文件类型、大文件四个视图。
- 增加授权刷新、实时进度、停止扫描和大文件搜索。
- 通过飞牛统一网关和管理员登录访问，应用不再开放 8787 网络端口。
- 图标资源改名，帮助系统刷新旧图标缓存。

## 测试安装

Intel / AMD 设备选 amd64；ARM64 设备选 arm64。在应用中心手动安装对应的 0.1.1 包升级，保留原授权。

安装后使用管理员账号重新打开“磁盘瞭望”。选择已授权目录，点击“开始扫描”。若显示启动时授权目录提示，修改授权后先停止并启动应用，再刷新目录。

本版本保持只读。fnpack 校验和本机测试不等于 fnOS 真机验收；如页面未打开或授权读取失败，请保留错误文字和应用日志用于定位。
