# DiskLens 0.3.3 正式发布验收清单

状态：开源测试版。用户已确认应用中心基础真机验收完成；详细证据不足的项目仍保持未勾选，不标记为完整正式版。

## 已完成

- [x] Go 1.26.9 `go test -race ./...`、`go vet ./...` 和 `govulncheck ./...` 通过，0 个项目可达漏洞。
- [x] 完整浏览器功能与 375/620/800/1100 宽度回归通过。
- [x] fnOS Unix Socket 代理、Host 端口移除、管理员校验、跨站拒绝、无 CORS 和嵌入单标题回归通过。
- [x] ARM64/AMD64 FPK 的版本、ELF 架构、图标、权限范围、生命周期、许可证和内嵌 Go 版本校验通过。
- [x] 当前两个 FPK 摘要已写入发布候选说明，旧 Go 1.26.4 包明确停止分发。

## ARM64 真机必选验收

- [x] 用户于 2026-10-20 确认当前 0.3.3 已完成应用中心基础真机验收；公开仓库未附设备版本、CPU 架构或原始日志。

- [ ] 使用 fnOS OAuth PKCE 建立 `trim-cli` 会话，不使用 SSH 密码代替平台授权。
- [ ] 应用中心 dry-run 通过，并从已安装 0.3.0 直接升级到 0.3.3。
- [ ] 桌面图标、名称、左侧导航和单标题 iframe 正确，页面显示 `v0.3.3`。
- [ ] 正常扫描、停止、设置保存成功；跨站、缺少请求标记和非管理员写请求仍被拒绝；无 CORS 响应头。
- [ ] 新增授权目录后可见，撤销任一扫描根授权后对应快照、导出、比较和重复结果立即不可见。
- [ ] 两个目录、父子重叠、排除规则、目录下钻、全局筛选/排序/分页和 CSV 下载结果正确。
- [ ] 使用已知相同/不同内容文件验证重复检测、限速、停止和文件变化拒绝，源文件均未修改。
- [ ] 停用/启动及 NAS 重启后历史、账单、提醒和巡检设置保留，未完成任务不会伪装成成功记录。
- [ ] 至少运行一个完整定时巡检周期，并在较长扫描和低速重复检测期间观察停止时限与资源占用。
- [ ] 卸载向导分别验证保留/删除应用数据，不删除授权共享目录中的用户文件。
- [ ] 获取概览、目录、账单、重复检测和设置的脱敏 fnOS 真机截图。
