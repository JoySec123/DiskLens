# DiskLens 0.2.0 开发顺序与验收

## 本轮目标

在 0.1.1 白色工作区、左侧导航和 fnOS 授权基础上，完成一个可部署的只读空间分析版本。参考清理工具的分析能力，不照搬 Windows 清理功能，也不在本轮加入删除、迁移或自动清理。

## 开发顺序

1. **完整索引与扫描范围**：用纯 Go SQLite 保存扫描元数据，支持多个授权目录、重叠目录去重、排除目录及通配规则；取消或失败不发布完整快照。扫描过程仍显示进度、可停止。元数据索引存入应用数据目录，不写入被扫描目录。
2. **日常分析**：目录逐层查看与面包屑；全量文件按路径、类型、扩展名、最小/最大大小、修改时间筛选；排序、分页、复制绝对路径。显示存储文件系统容量，与扫描文件逻辑大小分开，不重复累加同一文件系统。文件管理器深链仅在确认官方接口后接入，本轮使用可验证的复制路径。
3. **记录与对比**：扫描记录持久化、重启恢复、查看历史；同范围与同排除规则快照比较总量、目录增长及新增/消失/变化文件；导出当前完整筛选结果 CSV。保留最近 20 次成功扫描，清理的仅为应用索引。CSV 防公式注入。
4. **重复文件**：按大小预筛，流式全内容 SHA-256 后逐字节确认，分组展示；检查文件在扫描后是否变化、跳过硬链接别名及符号链接；提供进度、限速与取消。不删除文件，不把重复逻辑大小标作实际可回收空间。
5. **交付验证**：Go 测试与竞态检查、浏览器实际操作与移动端截图、Linux amd64/arm64 编译、fnpack 构建、包内容验证、发布说明。真机网关及 ACL 验证须用户部署完成，不以本机测试替代。

## 实现约束

- 所有查询、导出、历史和重复检测沿用实时授权；授权撤销后不得继续暴露旧快照路径。
- 扫描结果是逻辑文件大小；硬链接、稀疏文件、快照、压缩和写时复制都会使它与物理占用不同。
- 文件修改时间不是最近访问时间，不据此宣称文件无用。
- 文件系统调用阻塞时取消需要等待调用返回；长任务明确显示状态。
- 全量数据由后端筛选与分页，不能用前 50 项模拟全盘搜索。
- 同一进程同时只执行一个磁盘分析任务，限制重复检测读取带宽。
- 历史不是实时文件状态；两次扫描间新增/消失按路径比较，不推断为搬迁或删除。
- 错误、无授权、空结果、扫描中、取消、历史失效、接口失败均有明确状态。

## 后续单独评估

文件迁移需要冲突策略、空间预检、校验、断点恢复、权限/元数据保持和操作日志，影响其他应用引用。文件删除还需要回收站及恢复机制。以上不与本轮只读分析捆绑交付。
